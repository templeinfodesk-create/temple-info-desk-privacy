Privacy Policy

Last updated: September 14, 2026

srikrishnastories999 helps users fill TTD booking forms with details they choose to save.

Data stored

The extension stores names, ages, gender, photo-ID type and number, email address, city, state, country, pincode, and Gothram locally in Chrome storage on the user's device.

How data is used

Saved data is used only to fill matching fields on TTD booking pages after the user navigates there. The extension does not submit forms, make payments, or send saved data to the developer or any third-party server.

User control

Users can edit individual entries or use “Delete All Saved Data” in the extension popup at any time.
